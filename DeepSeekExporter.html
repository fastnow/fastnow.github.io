DeepSeekExporter

DeepSeek 对话导出器

完整历史拉取 六种导出方式 保留思考链 MD格式全渲染 开源免费
安装 DeepSeekExporter

需要 Tampermonkey 或 Violentmonkey

核心功能

不只是复制粘贴 —— 拿到的是结构化、可读、可直接归档的对话全文。

完整历史拉取

优先读取接口返回的完整对话，不受页面"只渲染当前窗口"的限制。接口不可用时自动降级为逐步滚动加载。

六种导出格式

Markdown 保留原始排版；PDF 走浏览器打印（真 PDF，文字可选）；Word 保留表格与代码块；另有 HTML、JSON、TXT。

格式完整还原

标题层级、代码块（自动识别语言）、表格、列表、引用、公式全部保留，不再退化成一坨纯文本。

思考链独立

深度思考内容与正文分开呈现，不会混进回答里。可一键选择是否导出思考过程。

顺序严格还原

按消息链还原真实先后：老对话在上、新对话在下，提问与回答严格配对，不会串位。

可拖拽面板

悬浮球与面板标题栏均可自由拖动，位置自动记忆。同时支持鼠标与触摸操作。

纯本地处理

所有解析与打包都在浏览器内完成，不连接任何第三方服务器，不上传、不收集对话内容。

安装与使用

三步开始，无需配置。

  1. 安装浏览器扩展 Tampermonkey 或 Violentmonkey
  2. 点击上方「安装 DeepSeekExporter」，油猴弹出安装界面，点击「安装」
  3. 打开 chat.deepseek.com 的任意对话，右下角出现悬浮按钮
  4. 点击「开始抓取」，脚本自动加载全部历史，实时显示已抓条数
  5. 悬浮球与面板标题栏可拖动改变位置，位置会被记住；触摸设备同样适用
  6. 抓取完成后出现导出区，选择 Markdown / PDF / Word / HTML / JSON / TXT 即可保存

配置项

面板内开关，即时生效并记住选择。

选项说明
导出思考链是否把深度思考内容一并写入导出文件，默认开启
严格去重合并内容重复的消息，默认开启
折叠超长代码超长代码块折叠为摘要，避免单条回答撑爆文档
YAML 元数据在文件头部写入标题、来源、导出时间、消息数，便于导入 Obsidian / Notion
面板位置拖动悬浮球或面板标题栏即可移动，位置自动保存，无需手动配置

风险与注意事项

使用前请留意

  • 仅作用于 DeepSeek：脚本只在 chat.deepseek.com 生效，请勿在隐私页面使用。
  • 需在对话页内使用：分享页（/share/…）为只读快照且无接口权限，只能解析当前已渲染的内容，可能不完整。
  • 登录状态：接口读取依赖登录凭证。若提示未走接口，请刷新页面后重开对话再抓。
  • PDF 导出：通过浏览器打印生成，在弹出的打印窗口中选择「另存为 PDF」。
  • 超大对话：数千条消息的对话滚动加载耗时较长，属正常现象，进度条会实时显示。

常见问题

为什么只抓到十几条？更早的对话呢？

页面用虚拟列表，只渲染当前窗口，滚动不一定能触发全部历史。脚本会优先走接口读取完整对话；若提示「未走接口」，多为登录凭证未取到，刷新页面后重开对话再抓即可。状态行显示「来源 API」时即为完整历史。

导出的顺序不对，提问和回答串了？

脚本按消息链还原真实先后。若你发现顺序异常，请确认用的是最新版本（面板顶部显示脚本版本与页面构建号）。仍有问题可点面板内「复制诊断信息」反馈。

思考过程和正文混在一起？

默认会分离。若某条回答的思考区未被识别，会被当作正文。可在面板关闭「导出思考链」后重新导出。

我发的图片消息丢了？

纯图片消息的正文为空，脚本会写入 [图片] 占位符，不会整条丢弃。

代码块里混进了「复制」「下载」按钮文字？

已在解析时剥离按钮类元素。若仍出现，说明页面结构有变化，欢迎通过 Issues 反馈。

脚本会收集我的对话内容吗？

不会。所有解析与打包都在本地完成，不发送任何外部服务器（资源下载请求除外，本脚本实际不发起任何外链请求）。
